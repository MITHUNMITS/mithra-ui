Introduction

Mithra UI is a collection of framework-independent custom elements styled dynamically with HSL tokens. Build faster, responsive, accessible web layouts.

Why Mithra UI?

Native Web Components: Rendered under Shadow DOM contexts ensuring total encapsulated stylesheets. No bleed-in of external styles.

Zero Tooling Dependencies: Works cleanly inside raw HTML files, statically served sites, React, Svelte, Vue, or Angular without compiling wrappers.

Modern CSS Properties: Configured to use a unified theme configuration that updates layout margins, surface colors, typography scales instantly.

Installation

Quickly configure Mithra UI web components in your project pipeline.

NPM CLI Installation 
npm install @mithra-ui/web
Setup / Register Web Components 
import { register } from "@mithra-ui/web";
import "@mithra-ui/web/theme.css";

// Register custom elements (m-button, m-text, m-icon, etc.)
register();
